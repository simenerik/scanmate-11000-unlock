ScanMate 11000 - quick install
==============================

Needs: Python 3.7 or newer (no libraries). Full detail in README.md.
Unzip everything to a folder first, for example C:\scanmate.


0. BACK UP
   Copy CQscan.exe somewhere safe.
   From the service console, save a "*" dump - that is your calibration record.
   No EPROM programmer needed. If you own one, reading both chips first is cheap
   insurance, but the boot block is locked and cannot be overwritten.


1. SCSI ADAPTER

   Open PowerShell as administrator: Start, type powershell, right-click,
   Run as administrator. It starts in C:\Windows\System32, so go to your folder first:

     cd C:\scanmate

   Then run the check. The -ExecutionPolicy part is needed because Windows blocks
   scripts by default:

     powershell -ExecutionPolicy Bypass -File .\tools\Get-ScsiPortCaps.ps1

   If a port already reports 58 or more MaximumPhysicalPages, you need 229,452 bytes and
   it already covers that - change nothing.

   If it reports fewer and the card is an Adaptec on aic78xx, run this as ONE line:

     reg add "HKLM\SYSTEM\CurrentControlSet\Services\aic78xx\Parameters\Device" /v MaximumSGList /t REG_DWORD /d 65 /f

   Reboot, then run the check again to confirm.

   This command overwrites the value, so it LOWERS it if something already set a higher
   one. Check the current value before writing, and keep the larger of the two.
   On another driver the key has no effect - find that driver's own parameter instead.


2. COLORQUARTET

   Close ColorQuartet first. In the same administrator window:

     python tools\patch-cqscan.py "C:\Program Files (x86)\Esko-Graphics\ColorQuartet Pro 5.2\CQscan.exe"

   If "python" opens the Microsoft Store, use "py" instead of "python".
   On 32-bit Windows the folder is C:\Program Files, without (x86).

   Backs up to CQscan.exe.original, applies everything in one pass, verifies each step,
   and refuses to run twice.

   Already patched with 2.0 or 2.1? Skip this step. The patcher applies exactly the
   same bytes in every 2.x release.


3. FIRMWARE

   CQscan -> firmware update -> firmware\SCA04000_pool6800.A6
   Wait for it to finish, then power cycle.
   The service console (9600 8N1, thumbwheel 8) prints:  A8FF

   Already on A8FF? Skip this step. The firmware has not changed since 2.0.


4. RECALIBRATE

   A flash rewrites all the gain tables to factory defaults. Run a white calibration:
   preview, crop about 20 x 20 mm of clear drum, then Calibrate. About 3 minutes.
   Save a "*" dump afterwards and compare it with the one from step 0.


5. TEST

   Narrow first: 5,000 px 8-bit, a few hundred lines. The console should report several
   buffers and "All lines transferred". Look at the image.

   Then wide: 30,000 px at 16-bit. The console should report 2 buffers.
   Two is the minimum. If it ever says 1, power cycle rather than let it hang.

   First scan over 2 GB: run  python tools\bigtiff.py verify <file>
   It must say VALID. (Above 4 GB has been tested only in emulation.)
   Save big scans to an NTFS or exFAT drive. FAT32 cannot hold a file over 4 GB.


ROLLBACK
   Firmware: flash firmware\SCA04000_pool.A6   (27,300 px, marker A5FF)
   Host:     restore CQscan.exe.original


IF A SCAN HANGS
   Power cycle the scanner. No damage. The host's abort does nothing, because the
   firmware is in an untimed poll loop.
